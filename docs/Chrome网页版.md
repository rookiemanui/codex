# 在Chrome中打开账本

本软件本身是网页版：Python提供网页和数据库服务，Chrome显示界面，不用安装桌面界面组件。
不能只双击localledger/web/index.html使用，因为它需要同一服务的记账、库存和图片接口。

## Windows

1. 将完整的软件包解压到D盘，例如 `D:\本地账本`。
2. 安装Python3.12（64位）和Google Chrome。
3. 双击 `用Chrome打开账本.bat`。
4. 程序启动本机网页服务，并自动用Chrome打开账本。输入启动窗口中的连接码；已设置密码时用原密码。
5. 保持启动窗口运行。关闭窗口会停止网页服务；数据仍在原data目录。

Chrome装在自定义位置时，可以在命令行指定：

```powershell
.\用Chrome打开账本.bat --chrome-path "D:\软件\Google\Chrome\Application\chrome.exe"
```

默认使用软件旁边的data目录。旧账本的data目录不要用空文件夹覆盖。
已有程序运行时先关闭旧启动窗口，或显式指定其他端口；不要因为网页暂时打不开而重复录入。
开启OCR仍需运行安装截图识别.bat；普通手工记账不需要OCR依赖。

## 本次云端浏览器

已在云端启动网页，并使用真实Chromium（Chrome同源内核）打开和核对已有账目。
当前聊天环境没有面向用户的端口转发/网页预览入口。云端浏览器不是你电脑的Chrome，也不能远程唤起你电脑上的Chrome。
不要把云端回环地址复制到自己电脑来访问，这两个地址指向不同机器。

若需要手机或电脑从外面访问云端运行的网页，仍需要可达的HTTPS入口。现有临时外网方案及尚未验收的限制见外网与支付接入.md。
此包增加了Chrome启动入口，并没有因此完成公网部署。Windows/安卓真机也尚未验收。
