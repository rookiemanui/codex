# 独立交互演示网页

`docs/index.html` 是独立、无后端依赖的演示网页，所有示例都是虚构的测试数据。
不读取实际账本、不调用记账服务，也不加载外部图片、脚本或字体。

支持：查看分类与总额、试记基础收支、搜索和筛选、模拟菜品收银与配方扣库、库存不足时拒绝整单、
模拟盘点、查看及打印演示小票。数据仅存在当前标签页内存，刷新或重置后恢复，不产生真实收款。
关联退款、截图OCR、日总额核对和完整备份属于Python完整版，不在此静态演示中实现。

## 直接查看

下载此HTML文件，用正常允许本地HTML的Chrome打开即可；不需要Python或安装依赖。
本云环境的浏览器策略禁止file协议，因此实际验证采用HTTP静态服务，不修改或绕过该浏览器策略：

```bash
python -m http.server 8766 --bind 127.0.0.1 --directory docs
```

这个命令只在运行它的机器提供网页，不能把云端回环地址当作用户电脑上的访问地址。

## 用GitHub Pages发布正式链接

页面和 `.nojekyll` 已在main分支的docs目录准备好。仓库管理者可以：

1. 打开 [仓库Pages设置](https://github.com/rookiemanui/codex/settings/pages)。
2. 在Build and deployment选择Deploy from a branch。
3. Branch选main，目录选/docs，然后Save。
4. 等GitHub构建完成，使用设置页显示的正式地址。

预期地址为 `https://rookiemanui.github.io/codex/`，**仅在Pages启用并成功部署后有效**。
GitHub Pages只能运行这份静态演示，不能托管Python记账后端。
本次云环境访问Pages管理API和github.io被出站代理403阻止，无法代替管理者启用或完成正式地址连通验收。
这是外部网络/配置阻碍，不是已经验证部署成功。

## 备用第三方预览

公开仓库中的HTML也可由 [raw.githack.com](https://github.com/neoascetic/rawgithack) 一类第三方服务转发为网页。
这不需要把私人账本上传给它；这里只允许使用本项目的公开测试页。
第三方预览的可用性不受本项目控制，不能作为正式记账服务。本云环境访问该服务同样失败，没有验证其实际页面链接。

## 验证

运行 `python scripts/smoke_demo.py`，需要开发环境的Playwright与Chromium。
覆盖金额精度、总额与分类变化、模拟销售收入和原料一致性、缺货整单拒绝、小票打印/PDF、搜索、重置和390像素布局。
同时确认网页没有发出API或外部资源请求。测试不打开实际账本数据库。
