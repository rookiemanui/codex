# 档口账本 Windows 便携版

适合一台 Windows 电脑保存账本、两位可信店铺成员共用。电脑的软件窗口、普通网页和同一 Wi-Fi 下的手机网页连接同一份数据。电脑需保持开机并运行账本控制台。

## 开始使用

1. 将完整便携压缩包解压到自己有写入权限的文件夹，例如 `D:\档口账本`。不要只取出 EXE，也不要从压缩包里直接运行。不要放到 `Program Files`。
2. 双击 `DangkouLedger.exe`。便携包已包含 Python，无需另行安装 Python。软件窗口使用电脑现有的 Edge 或 Chrome；没有这两种浏览器时，点击“打开普通网页”。
3. 在打开的记账界面输入控制台显示的六位连接码。已设置访问密码的账本仍使用原密码。
4. 手机与电脑连接同一 Wi-Fi，在手机浏览器输入控制台中的手机地址，再输入相同连接码。控制台可能列出多个网卡地址；选择店内网络对应的地址。
5. 两个人可以同时记账。软件窗口与网页共用一本账，不需要手动导出再同步。

双击 `练习账本.bat` 可使用独立的模拟账本。练习账本标有测试提示，存放在 `test-data`；正式账本在 `data`，两个目录互相隔离。请不要在练习账本录入正式账目。

## 每天开店与关店

打开控制台，再打开软件窗口或普通网页。关闭记账页面不会停止服务，手机仍可使用。关店时先确认需要的记录已经保存，点击控制台“安全退出账本服务”。退出会关闭服务并保留账本，手机页面会断开。第二天重新启动后连接码会更换。

只运行一个控制台。重复打开同一账本会提示回到原窗口，不会打开另一份账。若端口被其他程序占用，启动会报错，不会悄悄连接到那个程序。

## 数据与备份

正式数据默认保存在 `DangkouLedger.exe` 旁的 `data` 文件夹。控制台和网页设置页都显示具体位置。请完整保留软件目录，升级时先下载完整备份，关闭服务后按升级说明处理，不要用新软件目录覆盖现有数据目录。

每笔保存会产生数据库记录和独立备份。在“备份与设置”下载完整备份 ZIP，并定期另存到其他磁盘。保存在同一磁盘上的自动副本不能应对整块磁盘损坏。

恢复时点击控制台“从备份恢复到新文件夹”，选择完整备份 ZIP、保存位置，再输入一个新的文件夹名称。恢复会保留当前运行账本，并在恢复后的新文件夹中生成 `启动恢复账本.cmd`。先安全退出，再双击这个启动文件，即可打开恢复后的账本。不会自动覆盖或切换当前账本。

便捷启动文件使用当前软件的位置，请保留原软件文件夹。如果移动了软件，需重新生成启动文件或使用下方参数指定恢复目录。便捷启动文件生成失败时，账本恢复仍然有效，提示框会显示恢复目录和手动启动参数。任何已有同名启动文件都不会被覆盖。

指定数据目录和端口的例子：

```powershell
.\DangkouLedger.exe --data-dir "D:\店铺账目" --port 8765
.\DangkouLedger.exe --test-mode --data-dir "D:\独立练习账本" --port 8767
```

## 手机连不上时

确认电脑未休眠、控制台显示“正在运行”，手机使用相同 Wi-Fi。访客 Wi-Fi 可能禁止设备互相访问。Windows 防火墙首次询问时，可按店内网络需要允许专用网络通信；程序不会自动修改防火墙。VPN 或代理可能让控制台显示额外地址，需使用店内网卡的地址。

此便携版不自带外网发布入口。电脑关机后手机无法访问。需要离店后通过移动网络访问时，应另行确定部署与访问保护方案。

## 构建与验收（开发者）

使用 Windows x64 上包含 tkinter 的完整 Python 3.12。官方嵌入式 Python 包不保证带 tkinter，不适合作为本构建环境。构建依赖仅需 `requirements-packaging-windows.in`；不需要 Nuitka、Qt 或 pywebview。

```powershell
py -3.12 -m venv .packaging-venv
.\.packaging-venv\Scripts\python.exe -m pip install -r requirements-packaging-windows.in
.\.packaging-venv\Scripts\python.exe scripts\build_windows.py --output dist\windows
```

脚本生成目录式 EXE 包、ZIP、文件哈希清单和 ZIP 校验值。默认不打包个人数据、访问密码、OCR 模型或开发环境；每次构建使用新的输出目录，避免覆盖可能已运行并保存账本的旧目录。OCR 未包含，图片仍可保存后手工记账。

交付前在解压后的副本验收：双击启动、使用中文和空格路径、两个浏览器会话共用账本、记录收支并采购入库、重启保留数据、端口冲突和重复启动、下载备份并恢复到新目录、真实手机同一 Wi-Fi 连接。自动化测试能验证服务和锁，不能代替桌面显示与手机真机测试。未签名的 EXE 可能显示 Windows 的来源提示；不要将本包描述为已签名发行版。
