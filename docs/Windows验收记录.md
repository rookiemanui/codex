# Windows 0.4.0 验收记录

验收日期：2026-10-23。使用独立模拟账本，没有导入或修改真实营业数据。

## 已通过

- Windows x64 / Python 3.12：118 项自动化测试，117 通过，1 项仅适用 POSIX 的外网隧道模拟按平台跳过。
- 全项目 Ruff 检查与网页 JavaScript 语法检查。
- 餐饮浏览器流程：配方、购物车、收银、58/80mm 小票、退款；收银响应丢失后的结果核实；每日总额核对。
- 库存浏览器流程：采购同步支出、损耗不生成收入、已提交后断网与刷新恢复、403 时保留待核实请求、双独立会话共享、盘点冲突拒绝、撤销采购同时修正库存和收支、手录收入部分退款。
- Windows 控制台生命周期：重复运行及端口冲突保护，全新练习账本初始化，安全退出等待正在处理的请求和备份完成。
- 恢复：19 项备份测试，涵盖原生 ZIP 往返、路径校验、凭证和审计记录校验、现有账本保护，以及模拟账本标识保留。
- 最终便携包从全新中文/空格路径解压，核验 1001 个打包文件的 SHA256。冻结 EXE 能启动服务，两套浏览器会话读写同一份账本，重启后记录保留，下载的备份能还原。
- 桌面与 390px 手机尺寸界面截图已检查，手机账目金额可直接看见。

## 限制和待用户现场确认

- 手机尺寸测试在 Windows 浏览器进行，尚未连接用户的真实手机。同一 Wi-Fi 下的手机连接、路由器隔离及 Windows 防火墙放行，需在实际店内网络确认。
- 原生控制台已启动且窗口标题可见，但电脑操作工具的窗口读取权限请求超时，未完成原生窗口画面及文件选择对话框的人工点选验收。恢复逻辑与启动文件已由自动化测试验证。
- 便携 EXE 未商业签名。未进行公网部署，不含支付平台直连，也不含 OCR 模型。
- 开发依赖审计发现 certifi 2026.10.18 的已知问题，已更新为审计建议的 2026.10.19 并重建哈希锁。更新后的完整在线审计未获得结果，不能宣称最终环境“零漏洞”。基本记账运行代码使用 Python 标准库。
