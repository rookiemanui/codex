# 小锅账本安卓 App（0.1.0）

安卓 App 是 Windows 小锅账本的手机入口。收支、库存、订单和截图都保存在电脑原有账本中；手机不会创建另一份账，也不能在电脑关机时离线记账。支持 Android 8.0（API 26）及以上。

## 安装与连接

1. 在电脑上打开小锅账本，让服务保持运行。手机与电脑连接同一个可信 Wi-Fi。
2. 在电脑软件右上角点“连接与退出”，记下“手机地址”，例如 `http://192.168.0.113:8765`。电脑显示多个地址时，请选择店内 Wi-Fi 对应的地址。
3. 将 APK 复制到安卓手机并安装。首次安装时，安卓可能要求允许当前文件管理器安装应用；按手机系统提示操作。
4. 打开手机上的“小锅账本”，填入电脑显示的完整手机地址，点“连接账本”。以后会记住该地址；电脑 IP 变化时，点顶部“更换地址”重新填写。

连接后，手机与电脑实时读写同一本账。App 的截图选择会调用安卓文件选择器，备份 ZIP 和 CSV 导出会让你选择手机保存位置；销售小票可调用安卓打印界面。关闭手机 App 不会停止电脑服务。

## 连接失败

- 确认电脑没有休眠，Windows 托盘里仍有“小锅账本”图标。
- 手机与电脑使用相同 Wi-Fi；访客网络可能禁止设备互访。关闭手机 VPN 后可再试。
- 在电脑菜单里点“刷新地址”，把新的手机地址填入 App。`127.0.0.1` 只代表当前设备，不能填在手机上。
- Windows 防火墙首次询问时，根据店内网络需要允许专用网络通信。App 不会自动修改防火墙。

局域网 HTTP 地址仅接受私有 IPv4，例如 `192.168.x.x`、`10.x.x.x` 或 `172.16–31.x.x`；公网连接只接受 HTTPS。当前局域网账本默认直接访问，请只在可信店内网络使用。若电脑账本设置了独立访问密码，App 仍会要求输入该密码。

## 安装包与构建

仓库中的 `android/` 是原生 Android 项目。使用 JDK 17、Android SDK 36 和 Gradle 8.13，在 `android/` 目录执行 `gradlew.bat assembleDebug testDebugUnitTest`。构建得到 `app/build/outputs/apk/debug/app-debug.apk`。

此 APK 是方便本地安装测试的开发签名版本。它不使用你的正式发布密钥，也未上架应用商店；后续正式发布需要单独管理签名和升级路径。软件只申请网络权限；下载由安卓系统文件选择器确定保存位置，不需要读取整部手机的文件权限。
