# 小锅菜档口上手指南

适用：两个人经营，以鸡肉、小酥肉为主。一台 Windows 电脑保管账本，电脑软件和手机网页一起使用。

## 第一次打开

1. 完整解压便携包，双击 `DangkouLedger.exe`。保留打开的控制台。
2. 软件窗口打开后直接进入。正式账本没有模拟账目。
3. 手机连接同一 Wi-Fi，输入控制台“手机地址”即可进入。两人看到的是同一本账。
4. 先在“库存管理”添加鸡肉、小酥肉原料、食用油、打包盒等实际需要管理的项目。单位按你们的采购习惯选择；同一种原料保持同一单位，不要把斤与千克混填。
5. 已有原料通过“盘点”录入实际数量。补货线根据日常用量自己设置。

想先练习：运行 `练习账本.bat`。练习与正式账本分开保存，页面有模拟标识。

## 每日营业

- **采购鸡肉或小酥肉原料**：库存 → 入库 → 填数量；若尚未记录付款，勾选“同时新增一笔采购支出”，填写实付金额、账户与类目。这样库存和支出一起保存。
- **厨房领用、食材损耗**：库存 → 出库 → 选择领用或损耗。领用不要勾选销售收入。损耗不会自动生成收支。
- **销售收款**：点击“记一笔”选收入，可按日汇总、收款账户分别登记。已经逐单登记的收入不要再记一次日汇总。系统不会自动读取微信或支付宝收款。
- **水电、调料、打包盒等费用**：在“记一笔”选支出，按实际用途选择类目。在设置中可增加“打包耗材”等类目。
- **收摊核对**：查看收支概览和每日核对，与当天实际收款、付款核对。每日核对只作比较，不会再新增收入。
- **盘点**：可先在库存页下载“导出盘点表”并手填实盘数量，再回到软件逐项登记。CSV 只供核对，不会自动改账。如果另一人刚修改库存，系统要求刷新后再核对，避免覆盖对方的新记录。

收支结余是收入减净支出，不等于经营利润。本版不核算批次成本、毛利或税务报表。

## 录错或退款

- 采购数量或金额录错：在最近库存流水点“撤销录错”，填写原因，会反向记录库存并作废关联收支，随后重新录入正确数据。库存不足、已经退款、之后已做盘点或关联收银订单时会拒绝直接撤销，请先核对关联记录。
- 实际退给供应商：先记录“退供应商”出库；实际收到退款后，从原采购支出详情登记退款。
- 手录销售款退给顾客：先实际完成退款，再从原收入详情登记退款，支持部分退款。收银订单从“销售小票”退单。
- 库存保存后断网：不要新开一笔重复录入。恢复连接后在库存页点“核实上次操作”，系统会用原请求确认结果。

## 关店与备份

在“备份与设置”下载完整备份 ZIP，定期再保存到 U 盘或另一块磁盘。自动备份和账本位于同一台电脑，同一磁盘损坏时仍可能一起丢失。

恢复使用控制台“从备份恢复到新文件夹”。它先检查备份，再恢复到新目录，不覆盖当前账本。只支持本系统完整 ZIP 备份；CSV 用于查看，不能恢复完整账本。

关店时确认两人都保存完毕，在控制台点“安全退出账本服务”。电脑关机、休眠或控制台退出后，手机无法使用。

## 第一版边界

手机通过网页使用，可添加到主屏幕；没有单独的 Android 安装包。两位可信使用者共用访问码，没有员工权限分级。电脑需要持续运行，暂不提供离线手机补录同步或公网托管。截图可留存并人工录账，便携包未附带自动识别模型。
